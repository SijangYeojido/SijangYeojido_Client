2026년 6월 8일 Guideline 5.1.1(v) 반려 사유를 수정했습니다.

[5.1.1(v) 수정 내용]
- 앱 실행 후 로그인이나 회원가입 없이 홈, 전통시장 탐색, 시장 지도, 점포 목록, 점포 상세, 상품/특가 정보, 길 안내, 시장 정보 화면을 자유롭게 둘러볼 수 있습니다.
- 계정이 필요한 기능은 예약 생성, 쿠폰 받기, 예약 내역, 마이페이지, 상인/운영자 기능으로 제한했습니다.
- 점포 상세의 "점포 상품 예약" 버튼과 쿠폰 화면의 다운로드 버튼을 누를 때만 로그인 화면이 표시됩니다.

계정 기반 기능은 일반 회원가입 또는 운영 중인 OAuth 계정으로 확인할 수 있습니다.
전시/시연 빌드에는 공개 탐색용 목업 데이터가 기본으로 포함되어 있습니다.

[탐색 경로 - 일반 사용자]
1. 로그인 → 홈 → 신원시장 선택 → 시장 지도 → 점포 상세 → 특가 예약
2. 마이페이지 → 주문 내역 / 나의 쿠폰 / 내가 쓴 리뷰
3. 마이페이지 → 설정 아이콘 → 개인정보 관리 → 데이터 관리 → 계정 삭제

[탐색 경로 - 시장 상인]
1. 상인 계정 로그인 → 대시보드 → 상품 관리 → 점포/특가 관리

[탐색 경로 - 운영자]
1. 운영자 계정 로그인 → 운영 대시보드 → 시장/점포 승인, 신고 처리

서버 API: https://sijang-api.hyphen.it.com

[계정 삭제 안내]
계정 삭제는 앱 내부의 개인정보 관리 화면에서 완료할 수 있습니다.
삭제 확인 후 앱 세션, 기기 내 저장 토큰, 즐겨찾기 캐시가 제거됩니다.
